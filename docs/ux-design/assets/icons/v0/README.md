# OM Functional Icon Assets v0

Run 11B production-candidate assets.

- 66 semantic base SVGs in `svg/`
- 5 intentionally limited state variants in `variants/`
- `om-icons.svg` external symbol sprite
- `preview/contact-sheet.html` comparison surface
- 24-unit viewBox; 1.8 nominal stroke; `currentColor`; no literal color
- SVGs are `aria-hidden` by default; components own accessible names

These are not the OM brand/logo. They are the functional icon family.
