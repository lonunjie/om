# OM conversation-first UI shell prototype

Open `index.html` directly in a modern browser. It is a static, dependency-free visual/interaction prototype only; it is **not** production OM code and contains no OM cryptography/network logic.

Resize the window to see compact/mobile and expanded/wide layouts. The prototype reflects ADR-0159: the conversation workspace is persistent, there is no mandatory Chats/Calls/People tab bar, and the Omnibar exposes recognition-oriented suggestions plus local search/actions. Calls/People are represented as contextual/Omnibar destinations rather than permanent primary tabs.
