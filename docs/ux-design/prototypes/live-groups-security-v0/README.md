# Live / Groups / Security v0 fixture

R13B local fixture exercising the new state language without protocol/network implementation.

It demonstrates:

- incoming/active/reconnecting call states;
- privacy-preserving video answer controls;
- simple group vs optional Space/channel organization;
- `Verified by you` vs `Verification changed` wording;
- device revocation consequence wording;
- separated recovery scopes;
- provider route shown as diagnostics rather than trust score.

The fixture is illustrative, not human/device validation evidence.
