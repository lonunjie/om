# Identity validation v1 — Revision 12

Local-only blinded validation fixture for the three Revision 12 shortlist candidates. It measures open association, unwanted similarity, a synthetic app-grid findability task, and post-context name fit/memorability. Candidate internal names are hidden until the end.

This fixture does **not** perform legal/trademark clearance and does not upload results. Exported JSON must be analyzed separately. Synthetic app grids are not a substitute for real iOS/Android launcher testing.
