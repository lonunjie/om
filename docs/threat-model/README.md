# Threat Model Workbench

The full threat model is a Phase-0 deliverable and must be updated as Gates B–G freeze.

Minimum attacker classes:

- malicious unknown sender/spammer;
- malicious/compromised relay;
- malicious directory/equivocation;
- compromised user device;
- malicious group member;
- malicious bot/bridge;
- compromised storage provider;
- provider account suspension/deletion;
- network observer;
- dependency/supply-chain compromise;
- malicious third-party client;
- abusive organization agent.

Security claims must distinguish confidentiality, authenticity, continuity, availability, metadata privacy, and human recognition.
