## Design corrections

1. The canonical default shell is conversation-first; Calls and People remain first-class contextual/searchable surfaces but no persistent three-tab shell is required.
2. Omnibar adaptation is IdentityProfile-local, bounded, user-clearable/disableable, network-silent on mere typing, and never trust/identity/authorization evidence. Async result insertion cannot replace an armed target; learned destructive/security actions retain ordinary Core confirmation/authorization.
3. Functional semantic color roles and a stable semantic icon contract are explicit. Semantic/security action icons are theme-proof; untrusted theme icon assets are decorative only.
4. Activated theme bundles require validated light+dark variants and safe bounded relative assets. Theme content cannot own density, motion/reduced-motion or alert/accessibility behavior.
5. A user-pinned visual participant survives active-speaker call layout changes; face/hands visibility is treated as an accessibility requirement.
