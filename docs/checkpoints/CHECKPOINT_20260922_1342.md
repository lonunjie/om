# OM Architecture Checkpoint — 2026-09-22 13:42 PHT

## Focus

Shared cross-platform UI/UX architecture, motion/performance, accessibility and safe deep personalization.

## Canonical additions

1. One shared `om-ui` implementation above `om-core` for PWA/iOS/Android/Desktop official clients.
2. Platform-native shells own OS capabilities/system surfaces only; they do not fork messaging/security semantics.
3. Three primary destinations: Chats, Calls, People; Settings from profile/avatar.
4. Adaptive window layout: Compact/Medium/Expanded/Wide seed modes, based on available width rather than device identity.
5. PWA/native experience should be visually and behaviorally very close while respecting native system surfaces.
6. Telegram-class perceived smoothness is a product target achieved through immediate response, semantic/interruptible motion, optimistic local state where safe, stable layout and aggressive local caching—not ornamental animation.
7. Shared MotionSystem with reduced-motion mapping and prototype-tuned semantic timing tokens.
8. `OwnMessenger` themes are first-class but data-only: no code execution, remote tracking assets, message access or security-semantic overrides.
9. Local/bundled custom fonts are supported; remote font CDNs are not silently used. Font selection remains subject to readability/script/accessibility fallbacks.
10. Security-critical UI, focus indicators and semantic state are theme-proof.
11. Accessibility is implemented in shared primitives and treated as a release gate.
12. `om-ui` consumes Core view state and sends typed intents; it never manipulates keys, relay capabilities or AccountControlState directly.
13. `PlatformAdapter` is capability-oriented: secure storage, push, notifications, files/share, media, contacts-local, system calling, background execution, LAN, and later external transports.
14. Default visual direction: quiet, uncluttered, ergonomic, content-first, restrained, with aesthetics serving comprehension.
15. Search/command palette, Undo for reversible actions, state preservation and progressive disclosure become reference UX principles.
