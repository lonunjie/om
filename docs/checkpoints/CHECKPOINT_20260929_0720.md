## Scope

## Findings closed

1. **Terminal DeviceID revocation.** Canonical ACS prose said a removed messaging device could be linked again even though ADR-0131 forbids DeviceID reuse. ADR-0161 makes `permanently_revoked_devices` monotone across both messaging/control eligibility, updates the transition policy, and adds bounded no-resurrection evidence.
2. **Mutable availability-record convergence.** RelaySet and BlobLocationRecord had hash/version fields but no deterministic concurrent-writer semantics. ADR-0161 defines exact +1 continuity, branch retention/out-of-order reconsideration, current-signer eligibility and deterministic effective-record selection without changing frozen W0 shapes.
3. **HistoryBundle state isolation.** Group-history provenance existed but live-state isolation did not. ADR-0161 binds HistoryBundle to Room/author/recipient membership state and makes imported items bundle-local inert archive/display material that cannot enter live event dedupe or Room/control reducers.
4. **Crypto-floor domain ambiguity.** `AccountControlState.minimum_crypto_profile` is now explicitly the account-wide 1:1 floor ordered only by `security_generation.one_to_one`; group-only profiles are invalid for this field and Room/group floors remain independent.
5. **Stale T-133 residual.** The threat ledger still described the cleared-critical-bit problem as inherent after ADR-0157 had closed it. The residual text now reflects the actual remaining non-critical presentation risk.
