# OM Architecture Checkpoint — 2026-09-21 21:32 PHT

This checkpoint completes the Account Continuity / Trust / Discovery design pass requested after the 10:08 discovery-resilience snapshot.

## New canonical decisions

- recovery is optional and **off by default**;
- identity recovery, history recovery, and provider recovery are separate powers;
- random 256-bit offline recovery root and N-of-M guardian sharing are supported design paths; future threshold/MPC recovery remains pluggable;
- AccountControlState is a monotonic authenticated hash chain separate from chat events;
- emergency quarantine and permanent revocation are separate operations;
- quarantine cannot shrink the constitutional quorum denominator;
- new control-device promotion is a constitutional change, closing attacker-manufactured quorum attacks;
- compact AccountControlHead gossip/witnessing provides rollback/fork detection without external write authority;
- v1 infrastructure is user-owned Cloudflare, provisioned automatically where possible;
- `workers.dev` provides the zero-domain personal discovery FQDN; organizations/FQDN owners are the natural first grouped directories;
- personal v1 zero-payment core is Worker + SQLite Durable Object; R2 is optional because enabling R2 requires a subscription/checkout despite free included usage;
- Share Contact uses an Alice-signed, expiring ContactCapsule forwarded by Carol; optional referral context is not global reputation;
- software-update trust starts strong: forge-independent signed source/release identity, TUF-style roles, provenance, dependency pinning, reproducibility where feasible;
- privacy presets affect metadata/convenience, never the core crypto floor;
- push notifications remain available under strong defaults through opaque wakeups + local decryption/rendering; maximum-privacy users may disable vendor push with an explicit delivery tradeoff;
- backups restore content but never stale account authority;
- address-book upload/contact hashing is not part of v1; OS Contacts permission, if granted, is local-only;
- disappearing-message lifecycle and backup rules are explicit;
- critical/non-critical protocol extensions and public registries are defined before wire freeze;
- nation-state/anonymity transports remain optional adapters over stable OM semantics.

## Research corrections incorporated

- Cloudflare Workers accounts receive configurable `workers.dev` subdomains and per-Worker FQDNs.
- Cloudflare public OAuth clients support Authorization Code + PKCE for mobile/desktop/CLI clients.
- SQLite Durable Objects are available on Workers Free; exceeding Free limits causes relevant operations to fail.
- R2 requires an R2 subscription checkout; free allowance does not make it a no-billing-account dependency.
- Apple treats background/silent notifications as low priority and does not guarantee delivery, so "no APNs but still instant" is not a valid iOS promise.
- NIST 2026 crypto-agility guidance supports designing algorithm replacement as an operational capability.
- NIST's 2026 multi-party threshold call supports reserving a future standardized threshold-recovery interface rather than inventing one now.
- TUF, SLSA/in-toto, and reproducible-build practice support the update/supply-chain direction.
