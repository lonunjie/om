# ADR-0058 — Default UI Is Calm, Content-First and Ergonomic

- **Status:** Accepted
- **Date:** 2026-09-22

## Decision

The reference theme prioritizes ergonomics/functionality, immediate information access, low visual noise and peaceful visual hierarchy. Security is strong but not visually advertised through routine padlocks/cybersecurity decoration.

Personalization is broad and optional; the default remains the reference usability baseline.
