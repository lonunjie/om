# Security

This repository is the OM relay template (a signed, verified release of the OM reference Home). It is in open beta and has had no human
security audit; we make no security claim for it and offer no warranty or service level.

Report a vulnerability in the relay, the verifier or the release process privately through GitHub's
[private vulnerability report](https://github.com/lonunjie/om/security/advisories/new) for `lonunjie/om`; the policy and timings are in
[SECURITY.md there](https://github.com/lonunjie/om/blob/main/SECURITY.md). Do not post exploit details publicly and do not test against other
people's relays.

Fixes arrive as a new signed release of this template. There is no remote switch: nothing here can disable or change a relay you have deployed.
